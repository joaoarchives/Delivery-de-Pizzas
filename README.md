## 📌 Descrição

Sistema de gerenciamento de pedidos de pizza que utiliza **árvore binária de busca** para organização eficiente dos pedidos por tempo de entrega, com armazenamento em banco de dados **SQLite** e interface web interativa.

---

## ⚙️ Tecnologias Utilizadas

| Área | Tecnologias |
|---|---|
| Backend | Python, SQLite3, Flask |
| Frontend | HTML5, CSS3, JavaScript |
| Estrutura de Dados | Árvore Binária de Busca |
| POO | Abstração, Herança, Polimorfismo, Encapsulamento |
| Versionamento | Git, GitHub |

## 🚀 Como Rodar o Projeto

### Pré-requisitos

- Python 3.8+
- Pip
- Navegador moderno

### Passo a Passo

**1. Clone o repositório**
```bash
git clone https://github.com/joaoarchives/Delivery-de-Pizzas.git
```

**2. Acesse a pasta do projeto**
```bash
cd pizza-tree-system
```

**3. Instale as dependências**
```bash
pip install -r backend/requirements.txt
```

**4. Execute o sistema**
```bash
python app.py
```

**5. Acesse a interface**

Abra o arquivo `frontend/index.html` no navegador ou acesse `http://localhost:5000`

Este projeto foi desenvolvido para consolidar conhecimentos em:
